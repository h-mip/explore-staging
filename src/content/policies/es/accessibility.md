# Declaración de accesibilidad

Queremos que todo el mundo pueda usar este sitio web. Está diseñado para cumplir el nivel AA de las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.2.

Esta declaración se aplica a https://h-mip.com/explore. El sitio lo gestiona el Proyecto de Interacción Humano-Mosquito (H-MIP), un proyecto de investigación. No es un sitio web oficial de la Universitat Pompeu Fabra (UPF), del CSIC ni del Consejo Europeo de Investigación.

## Qué hacemos para que sea accesible

- Cada mapa tiene una alternativa en forma de tabla, y cada gráfico tiene una tabla de datos y una descripción textual.
- Todo el sitio se puede usar con el teclado.
- Las paletas de colores se han elegido para que las puedan distinguir las personas con alteraciones de la visión de los colores, y el texto se puede ampliar hasta el 200 %.
- El sitio respeta la preferencia de movimiento reducido del dispositivo.
- Todo el contenido es texto real, por lo que los traductores de los navegadores y los lectores de pantalla pueden procesarlo.

## Limitaciones conocidas

- El mapa interactivo puede ser difícil de usar con un lector de pantalla o sin ratón. La misma información está disponible en la vista de tabla de la página del mapa.
- No controlamos el contenido de otros sitios web que utilizamos o a los que enlazamos, como las imágenes del mapa base de OpenStreetMap y las páginas de Zenodo, GitHub y OSF.

Si detectamos otros problemas, los indicaremos aquí.

## Comentarios

Si tiene dificultades para usar alguna parte de este sitio, o necesita información en otro formato, escriba a **john.palmer@upf.edu**. Indíquenos la dirección web (URL) de la página y, si procede, el formato que necesita. Responderemos lo antes posible.

## Sobre esta declaración

Evaluado el 24 de septiembre de 2026 mediante pruebas automáticas y comprobaciones manuales con el teclado de la navegación, el mapa y su tabla alternativa, los gráficos, los controles para compartir y las vistas integradas. Se trata de una autoevaluación, no de una certificación WCAG independiente. Revisaremos esta declaración cuando cambie el sitio.
