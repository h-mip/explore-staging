# Declaració d'accessibilitat

Volem que tothom pugui fer servir aquest web. Està dissenyat per complir el nivell AA de les Pautes d'accessibilitat per al contingut web (WCAG) 2.2.

Aquesta declaració s'aplica a https://h-mip.com/explore. El web el gestiona el Projecte d'Interacció Humà-Mosquit (H-MIP), un projecte de recerca. No és un web oficial de la Universitat Pompeu Fabra (UPF), del CSIC ni del Consell Europeu de Recerca.

## Què fem perquè sigui accessible

- Cada mapa té una alternativa en forma de taula, i cada gràfic té una taula de dades i una descripció textual.
- Tot el web es pot utilitzar amb el teclat.
- Les paletes de colors s'han triat perquè les puguin distingir les persones amb alteracions de la visió dels colors, i el text es pot ampliar fins al 200 %.
- El web respecta la preferència de moviment reduït del dispositiu.
- Tot el contingut és text real, de manera que els traductors dels navegadors i els lectors de pantalla el poden processar.

## Limitacions conegudes

- El mapa interactiu pot ser difícil d'utilitzar amb un lector de pantalla o sense ratolí. La mateixa informació és disponible a la vista de taula de la pàgina del mapa.
- No controlem el contingut d'altres webs que fem servir o als quals enllacem, com les imatges del mapa base d'OpenStreetMap i les pàgines de Zenodo, GitHub i OSF.

Si detectem altres problemes, els indicarem aquí.

## Comentaris

Si té dificultats per utilitzar alguna part d'aquest web, o necessita informació en un altre format, escrigui a **john.palmer@upf.edu**. Indiqui'ns l'adreça web (URL) de la pàgina i, si escau, el format que necessita. Respondrem tan aviat com puguem.

## Sobre aquesta declaració

Avaluat el 24 de setembre de 2026 amb proves automàtiques i comprovacions manuals amb el teclat de la navegació, el mapa i la seva alternativa en forma de taula, els gràfics, els controls per compartir i les vistes incrustades. És una autoavaluació, no una certificació WCAG independent. Revisarem aquesta declaració quan canviï el web.
