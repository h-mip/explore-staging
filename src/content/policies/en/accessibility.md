# Accessibility statement

We want everyone to be able to use this website. It is designed to meet level AA of the Web Content Accessibility Guidelines (WCAG) 2.2.

This statement applies to https://h-mip.com/explore. The website is run by the Human-Mosquito Interaction Project (H-MIP), a research project. It is not an official website of Universitat Pompeu Fabra (UPF), CSIC or the European Research Council.

## What we do to make it accessible

- Every map has a table alternative, and every chart has a data table and a text description.
- The whole website can be used with a keyboard.
- Colour palettes are chosen to be distinguishable by people with colour vision deficiencies, and text can be enlarged to 200%.
- The website respects the reduced-motion setting of your device.
- All content is real text, so browser translation and screen readers can process it.

## Known limitations

- The interactive map may be difficult to use with a screen reader or without a mouse. The same information is available in the table view on the map page.
- We do not control content from other websites that we use or link to, such as the OpenStreetMap basemap images and the pages of Zenodo, GitHub and OSF.

We will list any other problems here as we find them.

## Feedback

If you have difficulty using any part of this website, or need information in a different format, write to **john.palmer@upf.edu**. Tell us the web address (URL) of the page and, if relevant, the format you need. We will reply as soon as we can.

## About this statement

Assessed on 24 September 2026 through automated checks and manual keyboard checks of navigation, the map and its table alternative, charts, sharing controls, and embedded views. This was a self-assessment, not an independent WCAG certification. We will review this statement as the site changes.
